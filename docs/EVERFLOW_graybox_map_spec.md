# EVERFLOW · 통합 임시 맵 제작 기획안

버전 1.0 · 2026-10-10 · Codex CLI 구현용

## 1. 작업 목표와 근거 수준

**기존 퍼즐 검증 씬을 보존하고, 새로운 게임용 씬에 퍼즐 6개를 복사하여 하나의 지형과 여정으로 연결한다. 최종 목적지는 거대한 물레방아다.** 임시 도형을 사용하되, 동선·높낮이·시야·실패 복귀·환경 복원·엔딩까지 게임의 기본 경험을 갖춘다.

이 문서의 좌표, 크기, 경사, 카메라 위치는 **이번 구현을 위한 신규 설계 제안**이다. 실제 Unity 씬이나 플레이어 성능을 측정한 값이 아니다. Codex는 프로젝트를 조사한 뒤 기능적 거리와 높이를 보정하고, 변경값과 이유를 기록한다. 기획서의 내용과 실제 구현을 구분한다.

| 구분 | 기준 |
|---|---|
| 확정된 방향 | 3인칭, 세 능력, 퍼즐 6개, 하나로 연결된 맵, 환경 변화, 최종 물레방아 |
| 자료상 현재 상태 | 핵심 기능 발표 자료에 퍼즐 6개 최소 구현 완료로 명시됨. 실제 코드 상태는 조사 필요 |
| 기존 기획 | BLOOM 성장, FREEZE 물 얼리기·움직임 정지, PULSE 장치 가동·전도 |
| 현재 사용자 지시 | 퍼즐 검증용 씬과 별개인 새 씬, 기존 퍼즐 복사·활용, 높이와 폭을 고려한 임시 맵 |
| 신규 제안 | 아래 월드 좌표, 지형 형태, 구역별 크기, 복원 표현, 카메라 배치 |
| 확인 필요 | 점프·꽃 도약·덩굴 이동·활강 거리, 능력 사거리·회수 규칙, 각 퍼즐 성공 조건, 6번의 정확한 고정 대상 |

기존 v1.0 기획서의 최종 장소 이름은 ‘세계의 원류’지만, 이번 씬에서는 후속 논의와 사용자 지시에 따라 **물레방아**를 최종 랜드마크로 사용한다. 잎 탑승·구체 공전 등 기획 요소는 실제 구현을 확인하고 재사용한다. 없으면 이번 맵 작업에서 임의로 전부 추가하지 않는다.

## 2. 플레이 경험

처음에는 물레방아가 멀리 보이지만 곧장 갈 수 없다. 플레이어는 왼쪽 식물 구간에서 올라가고, 높은 유적을 건넌 다음, 오른쪽 물길을 얼려 미끄러져 내려온다. 아래쪽에서 생명과 에너지의 연결을 완성하고 중앙에 도착한다. 마지막에는 물레방아가 돌고, 지나온 구역의 식물·물길·문양이 함께 회복된다.

동선은 **시작 → 01 꽃·덩굴 → 02 파편·석판 → 03 회전 구조물 → 04 얼음 슬라이드 → 05 뿌리·전도 → 06 최종 합류 → 물레방아·엔딩**이다.

넓은 한 공간 안에 순차 진행을 만든다. 길은 구불구불하게 연결하되, 진행 시간을 늘리기 위한 긴 빈 복도는 만들지 않는다. 기존의 8~9분은 기획 목표이며 실제 달성 시간으로 간주하지 않는다. 전체 크기는 첫 플레이 테스트 결과로 조정한다.

## 3. 좌표·축척·전체 배치

### 3.1 좌표 규칙

- Unity 월드 좌표 `(X, Y, Z)`를 사용한다. Y는 높이, +Z는 지도 위쪽/북쪽, +X는 오른쪽/동쪽이다.
- 1 Unity unit를 약 1m로 취급하는 설계안이다. 기존 프로젝트의 실제 캐릭터·물리 스케일이 다르면 그 스케일에 맞춰 환산한다. 캐릭터를 강제로 확대·축소하지 않는다.
- 아래 지면 높이는 발을 딛는 **상면의 Y**다. 두께 2인 바닥 도형의 중심은 상면보다 1 낮다.
- 전체 지형 외곽의 초기 작업 범위: `X=-90~90`, `Z=-75~75`인 약 180×150. 이 전체를 걸을 수 있는 평지로 만들지 않는다.
- 주요 구역이 차지하는 범위는 약 146×120. 나머지는 지형 어깨, 절벽, 카메라 여유 공간이다.
- 섬처럼 중앙과 능선을 둘러싼 외곽을 만든다. 부유 표현은 시각 옵션이며, 별도 물리 기능을 추가할 이유는 아니다.

### 3.2 구역 배치표

크기는 X방향 폭×Z방향 길이이며, 퍼즐을 배치할 **예약 영역**이다. 넓은 판 하나를 깔아 퍼즐 틈을 메우지 않는다. 실제 퍼즐 크기가 맞지 않으면 영역과 연결 지형을 늘린다.

| 구역 | 예약 영역 중심 X/Z | 예약 크기 | 지면 높이 | 진입 기준점 | 이탈 기준점 | 공간 역할 |
|---|---|---|---|---|---|---|
| S 시작 | `(0,-55)` | 24×20 | 0 | 스폰 `(0,0,-58)` | `(-12,0,-49)` | 중앙 물레방아 확인, 왼쪽 길 발견 |
| P01 식물 | `(-38,-43)` | 48×30 | 0→8 | `(-15,0,-47)` | `(-57,8,-30)` | 꽃 도약으로 상승, 덩굴로 서쪽 상단 연결 |
| P02 파편·석판 | `(-57,-2)` | 32×40 | 8→17 | `(-57,8,-20)` | `(-53,17,17)` | 무너진 능선을 발판으로 올라감 |
| P03 회전 구조물 | `(-24,36)` | 48×28 | 약 17 | `(-46,17,30)` | `(-2,17,40)` | 높은 능선의 좌우 단절 연결 |
| P04 얼음 슬라이드 | `(37,32)` | 64×30 | 17→4 | `(7,17,38)` | `(66,4,23)` | 동쪽으로 하강·도약·착지하는 하이라이트 |
| P05 뿌리·전도 | `(52,-13)` | 32×36 | 약 4 | `(58,4,4)` | `(38,4,-28)` | 하단에서 중앙으로 에너지 연결 |
| P06 최종 합류 | `(17,-16)` | 28×26 | 4→6 | `(30,4,-20)` | `(3,6,-12)` | 세 능력을 종합하여 중앙 진입 |
| W 물레방아 광장 | `(0,3)` | 28×14 | 약 6 | `(0,6,-12)`에서 접근 | 광장 내부 | 최종 작동·복원·엔딩 |

높이 0→8→17→4→6의 변화는 지형의 목표 윤곽이다. **기존 꽃이나 점프가 8m 상승하지 못하면 목표 지형 높이를 낮춘다.** 숫자를 맞추려고 플레이어의 능력이나 퍼즐 속도를 임의 변경하지 않는다.

### 3.3 지형 덩어리

| 덩어리 | 대략 위치 | 높이·형태 | 제한 |
|---|---|---|---|
| 시작 앞마당 | 남쪽 중앙 | Y=0, 낮은 지면과 얕은 파임 | 물레방아 조망을 막는 큰 벽 금지 |
| 서쪽 식물 절벽 | 남서쪽→서쪽 | 낮은 바닥과 Y≈8의 끊긴 선반 | 꽃·덩굴을 쓰지 않고 상단에 오르는 경사 금지 |
| 북서 유적 능선 | P02 주변 | Y≈8~17의 분리된 선반 | 파편을 쓰지 않고 통과하는 바닥 금지 |
| 북쪽 능선 | P03~P04 시작 | Y≈17의 두 덩어리 | 회전 구조물을 대체하는 뒷길 금지 |
| 동쪽 수로 경사 | P04 | 높은 수문에서 낮은 착지장으로 내려감 | 활강·도약 공간 안에 장식 장애물 금지 |
| 동쪽 하단 | P05 | Y≈4의 작은 안뜰과 중앙 접근부 | P06·물레방아로 내려뛰는 지름길 확인 |
| 중앙 물레방아 받침 | W | Y≈6의 단차 있는 광장 | 시작점에서 직접 오를 수 있는 연속 바닥 금지 |

시작점과 중앙은 가까이 보이지만 경로는 바깥 능선으로 돌아간다. 중앙 앞에는 끊긴 지면/낮은 협곡을 두고, 서쪽·동쪽 접근은 선반 높이와 지형 경계로 제한한다. 초기에 중앙 광장으로 점프해 들어갈 수 없는지는 실제 이동 성능으로 확인한다.

**높은 능선에서 중앙으로 내려뛰는 우회를 특히 확인한다.** 낮은 곳으로 떨어지는 점프는 같은 높이의 점프보다 더 멀리 도달할 수 있다. 위 예약값에서는 북쪽 P03 영역과 중앙 광장 사이의 최소 평면 간격이 약 12이므로, 이 간격을 충분하다고 가정하지 않는다. 실제 낙하 궤적으로 중앙에 닿으면 북쪽 능선을 바깥으로 옮기거나 중앙 광장의 걷는 영역을 줄이고, 공간에 어울리는 유적 경계로 접근을 제한한다. 필요한 경우 P03·P04를 함께 이동한다. 조망을 가리는 높은 벽 하나로 모든 문제를 해결하지 않는다.

## 4. 연결 길·폭·높이 기준

### 4.1 구역 사이 연결

| 연결 | 설계 |
|---|---|
| S→P01 | 왼쪽으로 꺾이는 폭 5~6의 짧은 길. 물레방아 조망 후 꽃이 있는 방향을 쉽게 발견 |
| P01→P02 | Y≈8의 선반을 따라 북쪽으로 연결. 길 폭 4~5, 진행에 불필요한 추가 점프 없음 |
| P02→P03 | Y≈17의 전망 선반. 물레방아와 다음 회전 장치를 함께 확인할 관찰 공간 배치 |
| P03→P04 | 같은 높이의 북쪽 능선. 폭 5~6, 수문·수로 시작 부분이 보이게 꺾음 |
| P04→P05 | 착지 후 감속 공간을 거쳐 남쪽으로 걷는 경사. 폭 6~8, Y≈4 유지 |
| P05→P06 | 중앙을 향해 서쪽으로 돌아오는 짧은 길. 폭 4~5, 끊긴 뿌리와 최종 구역을 연결 |
| P06→W | 마지막 성공 뒤 중앙 광장으로 이어지는 폭 5~6의 안전한 접근부 |

기준점 사이를 단순 직선 바닥으로 이어 퍼즐 틈을 덮지 않는다. 연결 길은 **앞 퍼즐의 이탈점과 다음 퍼즐의 진입점 사이에만** 놓는다. 높이가 같지 않으면 낮은 계단이나 완만한 경사를 사용하고, 퍼즐 내부의 장애물을 경사로 대체하지 않는다.

### 4.2 크기 권장값

| 요소 | 초기 설계값 | 보정 기준 |
|---|---|---|
| 일반 걷는 길 | 폭 4~6 | 플레이어 폭과 카메라 여유에 맞춤 |
| 넓은 관찰·조작 공간 | 8×8 이상 | 대상 조준과 카메라 회전 가능 |
| 퍼즐 발판 | 기존 발판 크기 우선, 필요시 안전 여유 추가 | 착지 허용 폭과 난이도를 확인 |
| 꽃 도약 착지장 | 6×6 정도로 시작 | 실제 도약 궤적·최고점에 맞춤 |
| 덩굴 착지장 | 8×6 정도로 시작 | 기존 놓기 타이밍의 착지 분포에 맞춤 |
| 일반 길의 경사 | 수평 대비 약 10~15도 이하부터 | 실제 컨트롤러 경사 제한으로 확인 |
| 얼음 슬라이드 폭 | 6~8 | 기존 활강 동작과 조향 성능 우선 |
| 슬라이드 착지장 | 약 14×12부터 | 최대 도약 궤적·충돌 크기·정지 거리에 맞춤 |
| 착지 후 감속부 | 진행 방향 8~12의 추가 여유 | 플랫폼 밖으로 미끄러져 나가지 않는지 확인 |
| 카메라 주변 공간 | 주요 조작 지점 뒤·옆 3~5 확보 | 현재 카메라 거리·충돌 설정에 맞춤 |

일반 점프의 거리·높이는 실제 측정한다. 안전하게 반복해야 하는 점프는 관측된 성공 범위보다 여유 있게 배치한다. 같은 높이에서의 최대 점프 거리를 다른 높이의 점프에 그대로 적용하지 않는다.

필수 단절은 일반 점프로 넘을 수 없지만 해당 퍼즐을 풀면 건널 수 있어야 한다. 두 범위가 겹쳐 우회를 막기 어렵다면 높이 차·옆 절벽·도착장 방향을 조정한다. 단순히 틈을 늘려 정답까지 불가능하게 만들지 않는다.

## 5. 물레방아와 가시성

### 5.1 임시 물레방아

- 광장 지면 Y≈6, 바퀴 중심 제안 `(0,18,3)`, 직경 24, 두께 3. 바퀴의 아래 끝 Y≈6, 위 끝 Y≈30.
- 바퀴는 XY 평면에 서고 축은 Z방향이다. 남쪽 시작점에서 바퀴의 원형 정면이 보이게 한다.
- 기둥 두 개·축·테두리·방사형 살·물 받는 판으로 구성한다. 정지 상태에서도 큰 원형 실루엣을 읽을 수 있어야 한다.
- 테두리는 작은 도형들을 원형으로 배치하고 살은 길쭉한 도형으로 만든다. 임시 단색 재질로 충분하다.
- 회전하는 바퀴와 고정 받침을 별도 오브젝트로 분리한다. 최종 작동 시 바퀴만 회전한다.
- 원거리에서는 단순한 외형만 보이고, 광장 접근 시 근거리 받침과 물길을 확인하게 한다.
- 물 공급은 북쪽 높은 수로에서 바퀴 상단으로 내려오고, 출수는 낮은 수로로 나가도록 높이 관계를 맞춘다. 실제 유체 시뮬레이션은 필요 없다.

### 5.2 ‘보인다’의 완료 기준

물레방아는 **시작점·각 퍼즐의 대표 관찰 지점·마지막 접근부**에서 식별 가능해야 한다. 지형 뒤에 잠깐 가려지는 이동 순간까지 항상 보이게 만들 필요는 없다. 특정 시점에서 퍼즐 6개와 물레방아 전체를 함께 볼 수 있는 별도 개요 카메라도 마련한다.

| 지점 | 보여야 하는 것 | 확인 기준 |
|---|---|---|
| 시작 `(0,0,-58)` | 바퀴 윗부분·축 주변, 왼쪽 P01 진입 | 기본 플레이 화면에서 원형 랜드마크 식별, 첫 길 발견 |
| P01 진입 | 꽃과 높은 도착 선반 | 능력 대상·이동 결과를 같은 관찰 위치에서 이해 |
| P01 이탈 | 중앙 물레방아와 P02 입구 | 앞으로 가는 방향 재확인 |
| P02 이탈 전망부 | P03 구조물, 중앙 물레방아 | 높은 곳에 도달했다는 공간 변화 |
| P03 진입/이탈 | 구조물 양끝과 수문 쪽 능선 | 회전 결과와 다음 구간 방향 확인 |
| P04 출발 | 얼음 경사·도약 끝·착지장 | 활강 방향에 착지장이 놓임, 착지 직전까지 시야 확보 |
| P05 관찰부 | 끊긴 연결 양끝, 물레방아 | 에너지가 어디로 가는지 파악 |
| P06 관찰부 | 세 대상과 물레방아 입력부 | 마지막 연결의 목적 확인 |
| 최종 개요 | 6개 구역의 자리와 물레방아 | 구역의 위치·복원 흔적을 한 화면에서 읽음 |

초기 조망 보호 구간은 대략 `X=-5~5, Z=-48~-5`다. 이 구간에 높은 절벽·기둥을 세우지 않는다. P06의 서쪽 경계가 가까우므로 중앙 조망 쪽 구조물은 낮게 유지하거나 뒤로 옮긴다. 이것만으로 가시성이 보장되지는 않으므로 실제 카메라 화면으로 확인한다.

전체 개요 카메라의 출발값은 위치 `(0,100,-95)`, 관찰 목표 `(0,8,0)`이다. FOV와 각도는 프로젝트에 맞춰 조정하여 전체 구역의 외곽을 화면 안에 넣는다. 이 값은 확정된 촬영 결과가 아니다. 검증용 개요 화면에만 S·01~06·W 라벨을 표시해도 된다.

플레이 화면에서는 라벨 대신 형태·높이·색·물길로 유도한다. 카메라가 멀다고 모든 퍼즐의 세부 기믹까지 읽힐 필요는 없지만, 구역 위치와 진행 결과의 큰 변화는 식별 가능해야 한다.

## 6. 퍼즐별 공간 구성

### P01 · 꽃과 덩굴 / BLOOM

**공간 역할:** 낮은 초원에서 첫 번째 높은 선반으로 올라가며 ‘환경을 바꾸면 길이 생긴다’를 경험한다.

- 진입부에는 시든 꽃을 배치하고, 뒤·위쪽에 도착 선반을 둔다. 꽃 외의 발판으로 올라갈 수 없는 단차를 만든다.
- 꽃을 피우면 밟을 수 있는 상면이 분명해진다. 기존 도약 기능을 재사용한다.
- 도약 후에는 넓은 중간 선반에서 덩굴의 고정점과 반대편 착지장을 확인한다.
- 성장 전 덩굴은 짧고, 성장 후에는 실제 잡는 부분·진자 운동 범위가 보인다. 기존 진자 이동을 재사용한다.
- 두 번째 단절을 건너면 P02로 이어지는 선반에 도착한다.
- 높이 0→8과 예약 폭 48은 시작값이다. 실제 꽃 도약 높이·덩굴 길이가 우선한다. 불가능하면 지형을 낮추거나 예약 영역을 조정한다.
- 복원 흔적 제안: 출구 주변의 작은 식물 덩어리 몇 개가 커지고 초록빛 연결 흔적이 능선 쪽으로 이어진다.
- 성공 기준: 꽃 사용만으로 완료하지 않고, 덩굴 이후 안전한 출구에 도달한 것을 확인한다.

### P02 · 낙하 파편과 회전 석판 / FREEZE

**공간 역할:** 더 높은 유적으로 상승하며 움직임의 적절한 순간을 고정한다.

- 남쪽 Y≈8의 관찰 선반과 북쪽 Y≈17의 출구 선반 사이를 끊는다.
- 기존 낙하 파편의 이동 궤적, 초기 위치, 재등장 방식과 회전 석판의 축·속도를 보존한다.
- 동결된 파편을 밟는 중간 구간과, 회전 석판을 건너는 후반 구간을 실제 기존 구조에 맞춰 배치한다. 두 기능이 구현되어 있다면 모두 포함한다.
- 능력 범위 밖에서 조준해야 하는 배치는 피한다. 파편과 출구를 같은 관찰 선반에서 확인하게 한다.
- 낙하 궤적 아래에 단순 지면을 채워 우회로를 만들지 않는다. 실패 시 복귀한다.
- 회전 석판을 고정한 뒤 플레이어가 올라섰을 때 충돌·접지 상태가 정상인지 확인한다.
- 복원 흔적 제안: 통과 이후 유적의 낮은 문양 띠가 다음 능선까지 이어진다. 반드시 쓰는 고정 발판은 복원 효과로 다시 움직이지 않는다.
- 성공 기준: 마지막 석판 너머의 안전한 출구 도착.

### P03 · 회전 구조물 / PULSE + FREEZE

**공간 역할:** 같은 고도에서 단절된 능선을 연결하며 가동→고정의 순서를 배운다.

- 서쪽 진입 선반과 동쪽 출구 선반을 Y≈17로 맞춘다.
- 중앙의 기존 회전 장치/기계팔을 복사하고, 작동 전에는 통과할 수 없는 틈을 둔다.
- PULSE 입력부는 진입 선반에서 사거리 안에 보인다. 회전하는 부분과 고정 축은 외형으로 구분한다.
- FREEZE로 적절한 각도에 고정했을 때 출구까지 연결되는지 확인한다.
- 예약 영역 48×28은 지형·조작 공간을 포함한 값이다. 기존 회전 반경을 48m 틈으로 강제로 늘리지 않는다.
- 움직이는 구조물의 전체 회전 범위를 둘러싸는 공간을 비운다. 회전 중 벽·플랫폼에 끼거나 플레이어를 밀어내는지 확인한다.
- 복원 흔적 제안: 통과 후 장치 받침의 문양이 켜지고 수문 방향으로 신호가 이어진다. 다리의 필수 고정 상태와 분리한다.
- 성공 기준: 장치 가동만이 아니라 반대편 출구 도착.

### P04 · 수문과 얼음 슬라이드 / PULSE + FREEZE

**공간 역할:** 최고 지점에서 하단으로 내려오며 환경 변화가 속도감 있는 이동으로 이어진다.

- 서쪽 출발부 Y≈17, 동쪽 착지부 Y≈4를 기본 윤곽으로 잡는다.
- 출발부에는 안전한 조작 공간과 수문을 두고, 수문 다음에 물이 나타나는 경사를 둔다.
- 물 생성→물 얼리기→활강→끝부분 도약→착지라는 기존 동작을 살린다.
- 경사의 수평 길이 약 35~45, 높이 감소 약 10~13, 폭 6~8을 후보로 사용한다. 실제 기존 활강 성능으로 보정한다. 경사는 대략 15~20도 수준의 출발안이다.
- 위 수치는 기존 퍼즐의 틈·속도를 덮어쓰라는 의미가 아니다. 우선 복사한 퍼즐에서 경사·도약·착지를 검증하고, 주변 지형을 맞춘다.
- 도약 끝과 착지장 사이의 틈은 실제 궤적으로 정한다. 일반 점프로 우회할 수 없고, 활강 도약으로는 여유 있게 도달해야 한다.
- 착지장은 약 14×12에서 시작하고, 진행 방향으로 8~12의 감속부를 추가한다. 두 공간이 겹쳐도 되지만 실제 정지 거리를 확보한다.
- 얼음 경사 가장자리에는 낮은 시각적 경계를 둔다. 실제 가이드 충돌을 추가할지는 기존 조향을 확인한 뒤 결정한다.
- 수문 지붕·유적 벽·나무가 출발 카메라나 착지장 시야를 가리지 않게 한다.
- 잎/이동체 탑승은 실제 구현되어 있을 때 사용한다. 없으면 맵 제작을 위해 새 탑승 시스템부터 만들지 않는다.
- 복원 흔적 제안: 얼음 주 경로와 별개인 옆 수로에서 물 흐름을 표시한다. 통과에 쓰는 얼음은 유지한다.
- 성공 기준: 지정 착지장에 도달하고 이후 P05로 걸어갈 수 있음.

### P05 · 뿌리로 잇는 전도 / BLOOM + PULSE

**공간 역할:** 내려온 흐름을 중앙으로 돌리며 식물과 장치가 같은 경로를 공유함을 보여준다.

- Y≈4의 안뜰에 시작 단자, 끊긴 연결 부분, 목적 장치를 배치한다.
- 세 요소가 한 관찰 지점에서 보이도록 U자형 벽·기둥은 낮게 둔다.
- 기존 뿌리 성장/연결 로직과 에너지 전달을 재사용한다. 성장 전에는 끊긴 간격, 성장 후에는 연결된 형태, PULSE 후에는 전달 방향을 읽을 수 있게 한다.
- 구역은 남쪽·서쪽으로 움직여 P06을 향한다. 시각적인 연결 방향도 중앙 물레방아 쪽으로 향하게 한다.
- 에너지 연결 퍼즐이 실제로 이동을 막지 않는다면 기존 완료 조건에 연동하는 간단한 출구 장벽을 사용한다. 임의의 두 번째 새 퍼즐로 만들지 않는다.
- 복원 흔적 제안: 목적 장치와 뿌리 경로가 켜지고 중앙 쪽 바닥 홈까지 이어진다.
- 성공 기준: 실제 목적 장치의 연결·활성화 조건 충족. 출구는 이 조건에 연동한다.

### P06 · 세 흐름 합류 / BLOOM + PULSE + FREEZE

**공간 역할:** 가까이 보던 물레방아에 도착하기 직전, 세 능력의 인과를 한 공간에서 완성한다.

- Y≈4의 동쪽 진입에서 Y≈6의 중앙 접근으로 연결한다.
- 기존 P06의 뿌리·장치·FREEZE 대상·최종 입력부를 모두 조사하고 복사한다. 코드에서 실제 의존 관계를 확인한다.
- 성장해서 연결됨→가동해서 필요한 상태가 생김→필요한 순간 고정됨이라는 조합이 실제로 구현되어 있는지 확인한다.
- 각 대상은 한 관찰 공간에서 위치를 파악할 수 있게 배치한다. 마지막 입력 방향에는 물레방아가 보여야 한다.
- FREEZE 대상이 물인지 움직이는 구조물인지는 실제 구현을 따른다. 기획 문구만 보고 다른 메커니즘으로 교체하지 않는다.
- 최종 PULSE가 실제로 별도 입력으로 구현되어 있으면 사용한다. 별도 입력이 없다면 기존 완료 이벤트를 최종 작동에 연결하고 차이를 보고한다.
- P06은 최종 능력 퍼즐이다. 물레방아 광장에서 새 7번째 퍼즐을 추가하지 않는다.
- 성공 기준: 실제 최종 조건 충족. 이전 다섯 구역의 완료도 확인된 상태에서 물레방아 작동으로 이어짐.

## 7. 진행·능력 사용·실패 복귀

### 7.1 진행 상태

- 퍼즐마다 안정적인 고유 ID `P01~P06`을 부여하고 완료를 한 번만 기록한다.
- 이동 퍼즐 P01~P04는 올바른 출구 도착으로 완료를 기록하되, 우회 통과를 막는 지형과 필요한 기능 상태도 함께 확인한다.
- P05·P06은 실제 연결·활성화 조건을 사용한다. 단순히 영역에 들어왔다고 완료시키지 않는다.
- 최종 작동은 여섯 완료 조건과 최종 입력/이벤트를 기준으로 한다. 입구부터 전체 퍼즐을 순서대로 해결할 수 있어야 한다.
- 화면의 작은 진행 표시 `0/6`은 검증용으로 사용할 수 있다. 플레이 화면을 디버그 글자로 덮지 않는다.

### 7.2 구체 회수와 남는 흔적

기획에는 구체 배치·회수가 있지만 실제 제약은 조사해야 한다. 각 능력 하나를 한 대상에만 유지할 수 있는 구조라면, 모든 구간에 효과를 영구 유지하는 것과 충돌할 수 있다.

- 기존 회수 규칙을 우선한다. 다음 퍼즐 진입 시 필요한 능력을 사용할 수 있는지 확인한다.
- ‘능력 효과 유지’, ‘구역 완료’, ‘환경 복원 흔적’을 별도 상태로 다룬다.
- 능력 회수 때문에 이전 구간의 식물·문양 복원까지 모두 사라지게 만들지 않는다.
- 회수한 뒤 재시도할 수 없거나 역주행 시 안전한 길이 사라지는 경우 복귀 지점·해당 퍼즐 재설정을 제공한다.
- 필요하면 통과 후 이동용 구조의 유지 방식을 보완하되, 구체를 임의로 복제하거나 모든 능력을 무한 사용으로 바꾸지 않는다. 실제 수정과 이유를 보고한다.

### 7.3 복귀 규칙

각 퍼즐의 안전한 진입부에 체크포인트를 두고, 출구에 도달하면 다음 구간 체크포인트로 갱신한다. 일반 추락 때는 현재 구간으로 복귀한다.

- 플레이어 위치뿐 아니라 속도·활강·덩굴 매달림 등 현재 이동 상태를 안전하게 정리한다.
- 움직이는 대상이 재시도 불가능한 위치에 고정되었다면 현재 퍼즐의 필요한 상태를 되돌린다.
- 이미 완료한 다른 구역의 기록·복원 흔적을 일반 추락 때문에 전부 지우지 않는다.
- 전체 다시 시작에서는 진행, 체크포인트, 능력 배치, 퍼즐 초기 상태, 복원 상태, 물레방아와 엔딩을 모두 초기화한다.
- 절벽 아래 복귀 판정은 맵 전체의 고도와 실제 추락 공간에 맞춘다. 높은 구간에서 긴 낙하를 기다리지 않도록 구역별 판정도 고려한다.
- 검증용 체크포인트 이동 기능은 개발 모드로 제한하고 정식 진행 판정으로 오인하지 않는다.

| 물 | 얇은 청록 면과 흐름 방향 표시, 능력 대상 여부 구분 |
| 얼음 | 밝은 파랑의 경사·발판, 물과 다른 형태/재질 |
| 뿌리·전도 | 연결선 도형과 노랑의 이동/맥동 표시 |
| 물레방아 | 원형 테두리·살·축·고정 받침·입수/출수 |

능력 관련 초록·파랑·노랑은 상호작용 대상과 상태에 집중한다. 모든 장식에 같은 색을 칠해 목표 후보가 지나치게 많아지지 않게 한다. 도형으로도 성장, 정지, 가동의 차이가 읽혀야 한다.

### 8.2 구역 복원

퍼즐 성공 후 해당 구역에서 큰 변화 하나를 보여준다. 주변 식물 덩어리의 성장, 문양 띠 점등, 옆 수로의 흐름 중 구역 역할에 맞는 표현을 사용한다. 기존 퍼즐의 발판·얼음·다리가 그대로 안전하게 작동하는 상태를 유지한다.

복원 흔적은 낮은 채도의 시작 상태와 뚜렷하게 달라야 한다. 다만 최초 세계 전체가 정지했다고 해석하여 P02의 낙하물·회전 석판까지 작동하지 않게 만들지 않는다. **퍼즐 동작과 세계의 복원 표현을 구분한다.**

### 8.3 물길 높이

- 높은 북쪽 수로에서 중앙 바퀴 상부로 내려오는 입수 경로를 만든다.
- 바퀴 아래에서 나오는 출수는 낮은 홈을 따라 시작 구역 및 동쪽 하단 쪽으로 이어진다.
- 높은 유적 구역의 최종 변화는 문양과 식생으로 보여준다. 낮은 물이 아무 장치 없이 능선을 거슬러 올라가는 표현은 피한다.
- 임시 흐름은 이동하는 빛 점·텍스처·짧은 물 띠 활성화 등으로 표현할 수 있다. 새 유체 시뮬레이터나 외부 패키지는 필요 없다.
- 물·문양의 시각 연결선을 전부 이동 가능한 충돌면으로 만들지 않는다. 진행 우회로가 되는지 확인한다.

## 9. 최종 작동과 임시 엔딩

1. P06 최종 조건과 여섯 구역 완료를 확인한다.
2. 물레방아를 정지에서 느린 회전으로 전환한다. 받침은 고정한다.
3. 입수와 출수 표현을 켜고, 이미 복원한 구역의 식생·문양에 추가 변화를 준다.
4. 짧은 조망 연출로 물레방아와 지나온 구역을 함께 보여준다.
5. EVERFLOW 표시와 다시 시작 기능을 제공한다.

임시 엔딩은 완성된 미술·음악 없이도 작동해야 한다. 카메라 전환 때문에 플레이어가 추락하거나 입력 상태가 꼬이지 않도록 안전한 상태에서 실행한다. 화면을 어둡게 덮어 맵의 복원 결과가 보이지 않게 하지 않는다.

최종 개요 화면에서는 여섯 구역의 위치와 물레방아를 같은 화면에 담는다. 정식 종료 연출은 이후 다듬되, 이번 구현에서 실제 프레임 또는 검증 화면을 확보한다. 확인할 수 없으면 미검증이라고 기록한다.

## 11. Codex 구현 순서와 산출물

### 단계 A · 실제 프로젝트 조사

AGENTS.md 등 지침, Git 변경 상태, Unity 버전, 씬·프리팹·스크립트·플레이어·능력 시스템을 확인한다. 각 퍼즐의 초기 상태, 완료 조건, 운동 범위, 참조와 복귀 기능을 정리한다. 조사 후 가능한 작업을 이어서 구현한다.

큰 지형, 단절, 연결 길, 물레방아, 착지장, 전망부를 만든다. 시작점의 중앙 조망과 각 구역의 대상·출구 가시성을 확인한다. 지도 좌표와 실제 배치의 차이를 기록한다.

### 단계 D · 진행·복귀·복원·임시 엔딩

퍼즐 완료 판정과 체크포인트를 연결한다. 능력 회수·재시도 가능 여부를 확인한다. 구역 복원, 최종 바퀴 작동, 전체 개요, 다시 시작을 연결한다.

### 단계 E · 검증과 보고

가능한 환경에서 에디터 실행·컴파일·플레이·빌드를 확인한다. Unity를 실행할 수 없는 환경에서는 참조·정적 검토와 자동 생성 작업까지만 사실대로 보고하고, 확인하지 않은 플레이·빌드를 성공으로 표기하지 않는다. 미설치 패키지를 임의 추가하여 작업 범위를 늘리지 않는다.

프로젝트에 재생성용 에디터 도구가 필요하면 이번 맵에 범위를 한정한다. 반복 실행으로 기존 작업을 삭제하거나 퍼즐이 중복 배치되지 않게 한다. 최종 결과는 생성 도구만이 아니라 사용자가 열 수 있는 새 씬이어야 한다. 환경상 씬 생성이 불가능하면 필요한 사용자 실행 절차와 미완료 범위를 명시한다.

작업 결과에는 다음을 포함한다.

1. 새 씬과 추가·수정 파일의 실제 경로.
2. 사용한 원본 퍼즐 및 변경한 참조·좌표 처리.
3. 최종 구역 좌표·높이·폭과 기획안에서 조정한 이유.
4. 가능하면 평면 개요와 주요 플레이 시점 화면.
5. 실제 검증 결과, 미검증 항목, 수동 확인 방법.
6. 원본 씬·공유 프리팹·시작 화면에 영향이 있었는지.

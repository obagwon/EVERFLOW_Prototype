# Everflow_Map 플레이 방법

대상: `Assets/Scenes/Everflow_Map.unity`. 타이틀 씬 `Assets/EverflowMVP/Scenes/Everflow_Title.unity`을 열고 Play → **게임 시작**으로 진입한다. 약 3초 동안 물레방아를 보여준 뒤 플레이어 조작이 시작된다. Map을 직접 Play해도 첫 퍼즐부터 시작한다.

이 문서는 현재 코드와 Unity 자동 Play Mode 검사를 기준으로 한다. 사람이 키보드·마우스로 처음부터 끝까지 플레이한 검증은 **미검증**이다. 검사별 근거와 한계는 [능력 검증 기록](Everflow_Map_AbilityValidation.md)에 구분했다.

## 조작표

`EverflowGraybox.EFInput`, `EFMapInput`, `EFMapPlayer`, `EFMapCamera`, `EFMapWorld`에서 확인한 조작이다. 프로젝트는 Both 입력 설정이며, Input System 사용 시 Keyboard/Mouse를 직접 읽는다. `InputSystem_Actions.inputactions`의 일반 액션 이름으로 조작을 추측하지 않았다.

| 입력 | 동작 |
|---|---|
| W / A / S / D | 카메라 방향을 기준으로 앞 / 왼쪽 / 뒤 / 오른쪽 이동 |
| 마우스 이동 | 3인칭 시점 회전. 우클릭을 누를 필요 없음 |
| C | 캐릭터 뒤로 시점을 맞추고 기본 아래보기 각도로 복귀 |
| 1 | BLOOM 선택: 꽃, 덩굴, 문 옆 뿌리, 마지막 수로 수리 |
| 2 | FREEZE 선택: 파편, 석판, 회전 다리, 물이 공급된 슬라이드, 마지막 흔들리는 수로 |
| 3 | PULSE 선택: 전력 수정, 성장 완료된 문 옆 뿌리 단자 |
| 마우스 왼쪽 클릭 | 화면 **중앙 십자 조준점**에 잡힌 대상에 선택 능력 사용 |
| Space | 일반 점프 / 개화된 꽃 돔 위에서 강화 도약 / 덩굴에 매달린 동안 놓고 건너기 |
| E | 성장한 덩굴 손잡이 잡기 / 물이 공급되고 얼어 있는 슬라이드의 나뭇잎 탑승 |
| R | 현재 미완료 퍼즐 초기화 후 해당 구간 시작으로 복귀 |
| Esc | 일시정지·복귀. 메뉴에서는 마우스 커서가 표시되고 잠금 해제 |

Esc 메뉴의 **Resume**, **Restart world**, **Title**은 커서로 클릭한다. 엔딩에서는 **Continue exploring**으로 조작을 복구하거나 **Restart world**로 전체를 다시 시작할 수 있다. 창 포커스를 잃으면 일시정지한다. 실제 OS 포커스 전환 조작은 미검증이다.

## 능력 사용과 해제

대상에 다가가서 중앙 조준점을 맞춘다. 조준점이 청록색이면 현재 능력을 사용할 수 있고, 노란색이면 대상은 잡혔지만 능력 종류·거리·선행 조건·현재 퍼즐 단계 등의 이유로 사용할 수 없다. 하단에 대상 이름과 이유가 나온다. 흰색이면 능력 대상을 잡지 못한 상태다. 클릭 실패 시 상단 메시지도 확인한다.

사거리는 **플레이어에서 실제 조준된 지점까지 10m**다. 긴 다리나 수로의 먼 중심 대신 가까운 부분을 조준한다. 카메라에서 보이더라도 플레이어와 대상 사이에 지형이나 벽이 있으면 사용할 수 없다. 앞 퍼즐을 완료하지 않으면 다음 구간 대상의 능력 사용이 차단된다.

FREEZE한 대상에 다시 2 + 왼쪽 클릭하면 동결이 풀린다. 여러 대상을 동시에 얼릴 수 있다. 독립 구체 투척·구체 회수 키·동시 유지 개수 제한·능력 쿨다운은 현재 Map에 구현되어 있지 않다. BLOOM과 PULSE는 같은 구간에서 유지된다. 이를 처음 상태로 되돌리려면 R을 사용한다. 완료된 이전 구간은 R로 초기화되지 않는다.

## ① 꽃과 덩굴

1. 시작 지점 앞의 닫힌 꽃 `SM_FlowerJumpPad`에 중앙 조준점을 맞추고 **1 → 왼쪽 클릭**한다. 꽃이 펴질 때까지 약 2초 기다린다.
2. 꽃의 열린 둥근 중심 위로 Space 점프해 올라간다. 돔 위에서 다시 Space를 누르면 앞쪽 높은 발판으로 도약한다. 이 발판에 체크포인트가 있다.
3. 높은 곳에 매달린 `SM_Vine`의 작은 새싹·덩굴 끝을 바라보고 **1 → 왼쪽 클릭**한다. 나무나 지형 대신 덩굴 자체를 조준한다. 약 1.6초 동안 줄기가 아래로 자라고 손잡이가 나타난다. 성장 후에는 마우스로 시선을 아래로 내려 손잡이를 찾는다.
4. 꽃 착지 발판에서 손잡이 쪽으로 접근한다. 손잡이가 다가왔을 때 **E**로 잡는다. E 판정은 손잡이에서 3.5m 이내이며 조준점은 필요 없다. 아래 바닥으로 내려왔다면 손잡이가 가까이 흔들려 올 때 **Space로 점프한 뒤 E**를 누른다.
5. 매달리면 자동으로 흔들린다. 다음 동쪽 발판 쪽으로 향했을 때 **Space**로 놓는다. 착지 보조가 적용된다. 꽃 도약과 덩굴 탑승·이탈을 모두 수행하고 동쪽 발판으로 가야 ②가 열린다.

성공하면 꽃과 주변 식생이 복원되고 안내가 P2로 바뀐다. 꽃 개화만으로 ①을 완료한 것은 아니다. 손잡이 잡기·놓기는 구현되어 있으며 자유 로프 조종은 구현되어 있지 않다.

## ② 낙하 파편과 석판

1. 동쪽 길 끝에서 첫 파편 `SM_FallingDebris_01`에 접근한다. **2**를 선택하고 파편을 조준한다.
2. 파편이 파란 높이 표시에 가까워질 때 클릭한다. 하단 `target offset`이 0에 가까워야 한다. 원래 씬에 놓인 파편 위치가 정답 정지 위치이며, 위에서 아래로 반복 낙하한다.
3. 파편 위로 점프해 이동한다. 첫 파편을 밟은 뒤 다음 파편에 접근해 같은 방법으로 `_02`, `_03`을 차례로 얼리고 밟는다. 시작 위치에서 세 개를 모두 얼리려 하면 먼 파편은 사거리 밖이다.
4. 너무 높거나 낮게 얼렸다면 **같은 파편에 FREEZE를 다시 사용해 해제**하고 다음 낙하를 기다린다. 정답 높이 허용 오차는 ±0.55m이며 그 안에서 사용하면 정답 위치로 맞춰진다.
5. 세 번째 파편에서 위쪽 길로 점프한다. 이어서 흔들리는 `SM_Slate`를 조준하고 **수평에 가까울 때 FREEZE**한다. 하단 각도가 0°에 가까워야 한다. 허용 오차는 ±8°다. 석판 위를 건너 길 끝으로 이동한다.

세 파편을 올바르게 얼린 상태로 실제로 밟고, 수평으로 고정한 석판을 통과해야 P3가 열린다. 세 파편과 석판의 FREEZE를 동시에 유지할 수 있다. 잘못 얼린 상태는 성공으로 판정되지 않는다.

## ③ 회전 다리

1. 동쪽 다리 입구 근처의 `SM_PowerSource_P3` 수정에 **3 → 왼쪽 클릭**한다. 수정이 밝아지고 `SM_RotatingBridge`가 회전하기 시작한다.
2. 다리 입구까지 접근하고 **가까운 다리 상판 끝부분**을 조준한다. 멀리 있는 회전 중심은 10m 밖일 수 있다.
3. 다리가 양쪽 길을 잇는 동서 방향으로 돌아왔을 때 **2 → 왼쪽 클릭**한다. 하단 각도 0° 부근(±8°)에서 고정한다. 여기서 0°는 모델이 원래 배치된 정답 자세 기준이다.
4. 다리를 건너 서쪽 출구로 이동한다. 잘못 고정했으면 같은 다리에 FREEZE를 다시 사용해 회전을 재개하고 맞춰 얼린다.

전원이 꺼진 다리에는 FREEZE가 차단된다. 서쪽 출구에 도착하면 P4 안내가 나온다. 능선을 따라 높은 곳의 수문과 잎이 있는 곳으로 올라간다.

## ④ 얼음 슬라이드와 나뭇잎

1. 능선을 끝까지 올라 `SM_PowerSource_P4` 수정에 **3 → 왼쪽 클릭**한다. `SM_WaterGate_P4`가 열릴 때까지 약 1.2초 기다린다. 수문 판이나 손잡이가 아니라 전력 수정을 조준한다.
2. 잎 옆에서 **수조 테두리 위로 Space 점프**해 올라간다. 수조 벽 너머 긴 슬라이드 입구의 수면 `SM_IceSlide/IceSlide_Surface`가 보이는 곳에서 **2 → 왼쪽 클릭**한다. 잎 위치에서 낮게 조준하면 수조 벽이 가린다. 먼 슬라이드 중앙·기둥·옆 수로를 조준하지 않는다. 수면이 얼음색으로 바뀌고 얼음 충돌이 활성화된다. 잎에서 슬라이드 옆 절벽으로 걸어 내려가지 않는다.
3. `SM_SideChannel`은 계속 물 상태로 남는다. 그쪽을 얼리는 조작은 없다.
4. 수조 테두리에서 **원래 잎 위치로 돌아와** `SM_RideLeaf` 가까이(3.5m 이내) 가서 **E**를 누른다. 능력 조준은 슬라이드, E 접근 판정은 잎이 맡는다. 물 공급과 슬라이드 동결이 모두 필요하다.
5. 탑승 후 자동으로 가속하며 활강·도약하고 다음 문 구간에 착지한다. 도착하면 **자동 하차**하고 WASD·점프 조작이 복구된다.

잎의 수동 조향·E 수동 하차는 구현되어 있지 않다. 길이 막히거나 탑승 중 얼음을 해제하면 체크포인트로 돌아간다. 정상 경로의 활강과 조작 복구는 자동 Play Mode로 검사하며, 모든 충돌 실패 경로는 미검증이다.

## ⑤ 덩굴 전선과 문

1. 잎 착지 지점에서 문 앞쪽 옆의 낮은 뿌리 `SM_VineRoot_P5`로 간다.
2. **이 뿌리에 1 → 왼쪽 클릭**한다. `SM_VineWire_P5` 전선 덩굴이 바위 위 전원 쪽으로 자란다. 약 2초 동안 연결이 끝나기를 기다린다.
3. **같은 뿌리 `SM_VineRoot_P5`에 3 → 왼쪽 클릭**한다. 뿌리가 원격 전원으로 전력을 전달하는 입력 단자다.
4. 위쪽 바위의 `SM_PowerSource_P5`를 직접 조준할 필요가 없다. 그 모델은 직접 능력을 받는 대상이 아니다. 덩굴 성장 전이나 성장 중에는 뿌리에 PULSE해도 연결되지 않는다.
5. 문짝 `SM_Door_P5`가 열린 뒤 통과하고 계단을 올라 마지막 고원으로 간다.

문을 직접 PULSE하거나 사거리를 늘려 원격 전원에 사용하여 조건을 생략할 수 없다. 연결 완료 후 같은 뿌리에 PULSE하는 것이 정식 해법이다.

## ⑥ 흐름 합류와 물레방아

1. 마지막 고원의 수로 옆 `SM_PowerSource_P6` 수정으로 가서 **3 → 왼쪽 클릭**한다. `SM_WaterGate_P6`가 열린다.
2. 부서진 수로 아래의 뿌리 구역 `P6_ChannelRepair`를 조준하고 **1 → 왼쪽 클릭**한다. 흩어진 수로 조각과 뿌리가 연결될 때까지 약 1.7초 기다린다.
3. 물레방아 쪽 마지막 흔들리는 수로 `SM_Channel_Swing_P6` 가까이 가서 조준한다. 수로가 앞뒤 고정 수로와 일직선일 때 **2 → 왼쪽 클릭**한다. 하단 각도 0° 부근(±7°)이 정답이다.
4. 수문 개방·수리 완료·마지막 수로 정렬/동결이 모두 유지되면 물이 순서대로 흘러 물레방아에 도달한다. 몇 초 기다린다.
5. `SM_Waterwheel_Wheel`만 회전하고 고정 몸체는 움직이지 않아야 한다. 최종 복원 연출 뒤 엔딩 카메라와 메뉴가 나온다.

잘못된 각도에서 고정했다면 FREEZE를 다시 사용해 풀고 정렬한다. 최종 물이 도착하기 전에 조건을 풀면 물 연결이 중단된다. 마지막 복원 완료 후에는 **Restart world**로 새 게임을 시작할 수 있다.

## 실패·체크포인트·능력 무응답 확인

- 추락하면 현재 체크포인트로 자동 복귀한다. 퍼즐의 성장·전력·동결 상태는 보존되고 잎은 출발점으로 복귀한다.
- R은 현재 미완료 구간의 능력 상태와 해당 구간 내 체크포인트를 초기화하고 구간 시작으로 되돌린다. 이전 구간 복원은 유지한다.
- 꽃 착지 발판과 파편 구간 중간 출구에는 조건부 체크포인트가 있다. 각 퍼즐 진입 시에도 해당 구간의 시작 지점이 저장된다. 저장되면 `Checkpoint saved` 메시지가 뜬다.
- 상단 P 번호가 맞는지 확인한다. 다음 퍼즐까지 걸어갔어도 현재 퍼즐의 실제 사용·통과 조건을 충족하지 않으면 다음 능력 대상은 잠겨 있다.
- 하단에서 `does not respond`는 능력 종류 오류, `Too far`는 사거리 초과, `blocked`는 지형/벽 가림, `BLOOM ... wire`는 전선 성장 미완료, `PULSE ... first`는 전원/물 공급 미완료다.
- 동작 후 외형이 즉시 바뀌지 않으면 애니메이션 완료까지 기다린다. 특히 문·수문·덩굴은 클릭 즉시 완료 처리되지 않는다.
- 덩굴·잎 E는 조준 대신 접근 거리로 판정한다. 손잡이나 잎에 가까이 가고 선행 조건을 확인한다.

개발용 진단은 플레이어 Inspector의 **Log Ability Attempts**와 **Draw Ability Gizmos**를 켠다. 전자는 클릭 시에만 능력·대상·Collider·성공/차단 이유를 출력한다. 후자는 Play 중 플레이어를 선택하고 Scene Gizmos를 켰을 때 카메라 조준선, 플레이어 시야선과 판정 영역을 그린다. 기본값은 둘 다 꺼져 있다.

# 8/9 위치·층별 목표 안내

`Everflow_Map_v2_test_with_puzzle` 씬에 선택 A를 적용했다. 왼쪽 위에는 현재 구역과 층, 퍼즐 진행 목표, 다음 연결부를 표시한다. 탑은 가장 낮은 층을 1층으로 세며, 계단에서는 가까운 층과 다음 계단참을 보여준다. 안내 범위 밖에서는 방향과 거리를 숨긴다.

- `EFV2RouteGuide.cs`에 계단참, 터널 모퉁이, 수조·수문 회랑의 연결을 등록했다. 플레이어 발 위치와 높이로 구역을 구분하며, 석문·덩굴·얼음길 등의 상태를 읽어 다음 연결부를 고른다.
- `EFV2Guidance.cs`에서 위치와 진행 목표를 분리하고, 방향과 거리를 왼쪽 위 한 줄로 표시한다. 둔덕의 B/C 선택과 D3·D5·D4의 복수 해법은 문구에 표시한다.
- `EFV2PuzzleWorld.cs`에서 다시 시작할 때 안내 진행 상태를 초기화한다. R로 복귀하면 현재 위치를 다시 읽고 퍼즐 진행 목표를 유지한다.

## Unity 검증

| 검사 | 결과 |
| --- | --- |
| [위치·복귀 검사](location-checks.txt) | 28/28. 같은 XZ의 다른 탑 층, 수조/수로 높이, 동결 전후, 뒤로 이동, R 복귀, 정원 도착과 재시작 |
| [B 뿌리 다리 연속 입력](route-bloom.txt) | 46/46. 덩굴, D5 우회 뿌리와 D4 뿌리를 거쳐 정원 도착과 재시작 |
| [C 잎 연속 입력](route-alternate.txt) | 63/63. 수조 얼음길, D5 정렬·고정, D4 수차를 거쳐 정원 도착과 재시작 |

연속 입력에서 기존 이동과 능력 입력으로 진행했다. B 연속 입력은 경계 조정 전, C 연속 입력은 마지막 문구 조정 전에 실행했다. 최종 위치 검사에서 경계와 문구를 다시 확인했다. [탑 계단 플레이 화면](route-alternate-tower-stairs.png), [얼음길 안내 화면](basin-open.png).

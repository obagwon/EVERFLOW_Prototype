# 지하 수력 시설 재설계

`Everflow_Map_v2_test_with_puzzle`에서 C안을 적용했다. 기존 플레이어와 퍼즐 장치의 접근 지점을 기준으로 상층 급수, 하층 저수, 정비 보행 공간을 다시 구성했다. 새 구조는 이 씬이 실행될 때 조립한다.

- **상층 D5**. 천장 낙수가 높은 석조 물받이로 떨어진다. 어긋난 상태에서는 측면 배수 홈으로 물이 빠지고, 정렬되면 물받이의 출구가 가동 수로 안으로 이어진다. 물 표면은 `PH_D5_MovingChannel`에 붙어 있다. 구조물을 고정하면 반대쪽 고정 수로와 낙수를 거쳐 D2로 공급한다. 내부 물을 얼리면 수로 안이 얼고 하류 낙수가 멈춘다.
- **하층 D2와 D4**. 모서리를 다듬은 저수조 수면을 낮은 석조 테두리로 감싸고, 정비 부두·작은 수차·주 출구에서 물이 빠지는 곳을 열었다. D4 문턱의 보행판은 수면보다 9cm 위에 두고, 수문 앞에는 수로와 석조 문틀을 배치했다.
- **건식 정비 동선**. D5의 데크와 짧은 경사로, D2에서 D4로 이어지는 외곽 데크를 각각 이어진 표면으로 만들었다. D3 계단 접합부의 옛 밧줄 다리와 새 수로에 겹치는 옛 테두리를 정리했다. D1과 부두 계단에는 연속된 석조 옆면을 더했다.

## Unity 확인

- [물 상태 검사 30/30](water-state.txt). 누수, 정렬, 고정, 내부 물 동결, 해동, D2 분기와 정원 복원을 확인했다.
- [단면 검사](d5-section.txt). 연속 입력 중 정렬·고정된 가동 수로에서 21곳의 수면 높이가 바닥보다 약 14cm 위였다.
- [형상 검사 10/10](geometry-checks.txt). 물받이 출구가 가동 수로 입구에 닿는지, 배수구 상인방이 통로 아래에 있는지, D4 문턱이 수면 위에 있는지 확인했다.
- [정렬·고정 경로 63/63](route-alternate.txt)와 [덩굴·우회 경로 47/47](route-bloom.txt). 키보드와 마우스 합성 입력으로 시작부터 정원에 걸어가 재시작했다. 두 경로는 저장된 씬으로 검사했고, 우회 경로 이후 내린 배수구 상인방은 최종 형상 검사에서 확인했다.

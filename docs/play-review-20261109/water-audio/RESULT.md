# 3/9 · 조용한 근거리 물소리 — A 적용

사용자 선택: 물소리를 약 10~12dB 낮추고, 실제 물 위치의 6~10m 근처에서만 들리며 얕은 물은 더 작게 한다.

## 적용 결과

- 물소리 전용 최대 게인을 12dB 감쇠했다. 기존 ambientVolume .18은 유지하고 물 루프에만 ×0.251189를 적용해 최대 .045214로 제한한다. 능력·문·복원·물레방아 효과음의 게인은 그대로다.
- AudioListener(실제 카메라 청취 위치)에서 실제 수면 삼각형까지 거리를 계산한다. 9m에서 목표 음량이 0이 되며 약 .35초의 변화 제한으로 부드럽게 감쇠한다. 순간이동은 이전 위치의 잔여 음량을 즉시 비운다.
- 큰 곡선 물길의 AABB는 빠른 제외 검사에만 쓴다. 수면 밖의 빈 땅을 물로 판정하지 않으며, 수중 두께·옆면 메시(UV2 Y=1)는 소리 위치에서 제외한다.
- 수면 방향이 수평에 가까울수록 폭포의 55%로 줄이고, 정체된 물은 여기에 25%를 더 곱한다. 물길 하나에 폭포와 얕은 하천이 함께 있어도 각 삼각형의 방향을 구분한다.
- 가까운 유효 후보 중 가장 크게 들릴 표면 하나를 선택한다. 기존 물소리 1개와 전체 12개 AudioSource 풀을 유지한다. 공간 패닝을 유지하되 거리를 두 번 감쇠하지 않는다. 별도 에셋/패키지/믹서를 추가하지 않았다.
- 메시/변환 캐시와 8Hz 질의를 사용한다. 가동 수로의 변환도 갱신한다. 실제 Editor의 따뜻한 질의 50회 평균 .976ms였으며 빌드 성능 측정값은 아니다.

## 변경 파일

- `Assets/EverflowMap/Runtime/EFDemoFeedback.cs`: 물소리 전용 설정, 수면 샘플러 연결, 재시작 시 캐시된 음량/질의 시점 초기화.
- `Assets/EverflowMap/Runtime/EFV2WaterAudioSampler.cs`: 실제 표면의 최근접점·거리·수면 방향 기반 게인, 정지/동결/숨김 물 제외.
- `Assets/EverflowMap/Editor/EFWaterAudioPlayChecks.cs`: 격리된 기하 검사, 실제 Play의 청취 위치/음량 검사와 Input System을 통한 모드 전환 검사.
- `Assets/Scenes/Everflow_Map_v2_test_with_puzzle.unity`: Unity API로 저장한 물소리 설정 3개만 추가. 직전 씬과 텍스트 비교에서도 이 3줄만 다르다.

## Unity 실행 검증

Unity 6000.3.21f1, 대상 씬에서 진행했다.

- **물소리 검사 41/41 통과**: AABB 안의 빈 공간, 얕은 물/수직 물 비교, 변환 이동, 동결/건조/숨김/수중 면 제외, 실제 수면의 소리 위치, 청취 거리와 음량, 먼 곳 무음, 능력 모드 4회 진입/취소, 일반 일시정지, 리스폰/재시작, 소스 수 유지, BLOOM 효과음 게인 유지.
- **기존 입력 검사 55/55 통과**: 실제 Input System의 키/커서·레이캐스트·사용 확정·FLOW 방향·취소·카메라·창 포커스 변경·재시작 경로를 유지했다. 자세한 결과는 `input-smoke.txt`.
- 이 항목에서 전체 퍼즐 경로는 다시 진행하지 않았다. 직전 자연 하천 작업에서는 정원까지 연속 입력 63개가 통과했다. 이번 변경의 검증은 오디오 및 입력 회귀 검사다.
- 퍼즐 월드, 낙하 복귀, 퍼즐 조립, 물 공급/동결 표현 로직, ContinuousWater.mat의 SHA256은 직전 백업과 모두 동일하다.
- 10.53초 녹화 `nearby-water-review.mp4`: 1280×720 H264 + 48kHz AAC. 고정된 카메라/청취 위치를 바꾸며 폭포 근처→빈 땅→얕은 하천→먼 곳과 정지/재개를 확인한 검사 영상이다. 자연스러운 카메라 이동 영상은 아니다.
- 녹화 파일 측정은 평균 -63.1dBFS, 피크 -43.7dBFS였다. 이전 사용자 영상과 위치/소리 구성/진행 시간이 달라 이 수치를 전후 감소량으로 해석하면 안 된다. 12dB는 물소리의 최대 게인 변경량이다. 사람의 청취 검증이나 사용자의 장치 볼륨 측정을 했다는 의미는 아니다.

## 보존과 남은 범위

기존 퍼즐, 능력의 적용/회수, 낙하 복귀, 캐릭터 모델, 물길 지형/재질을 보존했다. 전체 소리 음소거나 자동 볼륨 덕킹은 추가하지 않았다. 벽 차폐, 구역별 고정 소스, 환경음 믹서는 B안의 범위여서 이번에는 구현하지 않았다. 최종 체감 음량은 사용자 청취 후 추가 조정할 수 있다.

다음은 4/9 계단·다리 지지 구조 방식 선택이며, 아직 수정하지 않았다. 5~9도 선택 대기 상태다.

직전 소스와 씬은 `before/`에 보존했다. Unity 설치본의 AudioSource/SetCustomCurve 공식 로컬 문서를 확인하여 구현했다. 작업 종료 시 Play를 멈추고 Run In Background 및 자동 틱 임시 설정을 해제한다.

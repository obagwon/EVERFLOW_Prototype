# 5/9 · 기존 지형에 착지판과 뿌리 맞추기

`Everflow_Map_v2_test_with_puzzle`의 B 입구와 건너편에서 짙은 덧판을 걷어냈다. 제거 전 두 판의 면적을 각각 441점으로 검사했고, 지형은 모든 표본에서 기존 판보다 최대 9.3cm 아래에 있었다. 캡처에서 겹쳐 보였던 밝은 돌은 B의 움직이는 퍼즐 발판이다.

D4에서는 기존 석조 착지대 위에 놓인 체크포인트 판을 제거했다. B 입구, B 건너편, D4 제어 지점은 체크포인트 트리거와 저장 위치를 사용한다. G의 판은 밑면 검사에서 지형이 받치지 않는 가장자리 구간이 있었고, C 상단과 D5 횡단로도 간극을 잇는 발판이다.

B의 기존 뿌리 메시에는 떨어진 두 조각이 있었다. 모델을 180도 돌리고 길이축을 30%로 줄여 두 조각을 다리 입구에 모았다. D3 덩굴은 D1 보행로 안쪽으로 옮겼고, D4 뿌리는 주 착지면에 닿도록 9cm 내렸다. B와 D3의 능력 조준 위치도 옮긴 뿌리 근처에 맞췄다.

변경은 `Assets/EverflowMap/Runtime/EFV2PuzzleAssembly.cs`의 런타임 조립에 적용했다.

## Unity 검증

- 기하·접지 17/17 통과. 제거한 판의 충돌면, 체크포인트 트리거와 복귀 위치의 바닥, 작은 상태와 성장한 상태의 뿌리 접지를 검사했다. 결과는 `geometry.txt`에 있다.
- B 연속 입력 경로 46/46 통과. 커서로 B·D3·D4 뿌리를 조준해 성장시키고, 물레방아 복원과 정원 도착, Enter 재시작까지 진행했다. 결과는 `route-bloom.txt`에 있다.
- 발판·복귀 격리 검사 29/29 통과. 풍차와 돌 발판을 사용해 B 건너편에 도착하고, B↔C 교량 왕복과 맵 밖 낙하 복귀를 실제 입력으로 확인했다. 결과는 `platforms.txt`에 있다.

# 1번 · 낙하 복귀 개선 (A 선택)

## 변경

마지막 안전 지점보다 8m 아래라는 이유만으로 복귀하던 조건과 탑 내부 예외 좌표를 제거했다. 기존 고정 바닥/구조물의 전체 범위 X=-102..12, Z=-92..12에 2m 여유를 둔 X=-104..14, Z=-94..14를 플레이 외곽으로 저장했다. 이 범위 밖의 동/서/남/북 공간은 명시적 복귀 영역이다. 바닥에 서 있거나 점프 상승 중일 때는 외곽 복귀를 발동하지 않는다.

맵 안의 정상 바닥은 높이 차와 관계없이 착지 가능하다. 맵 안쪽 빈 공간으로 떨어져 바닥을 만나지 못하는 경우에는 기존 최하단 Y=-45 안전선이 처리한다. 공간 비교로 판정하므로 플레이어나 지형에 새 충돌체를 추가하지 않았다. 맵 확장 시 `EFV2PuzzleWorld.fallRecovery.playableXZBounds`도 함께 갱신해야 한다.

정원 복원 전에 높은 곳에서 최종 정원 바닥에 내려갈 수 있으므로, 복원 전에는 그 정원 체크포인트가 기존 안전 지점을 덮어쓰지 않도록 했다. 그 바닥에 서는 것은 허용되며 R로 이전 안전 지점으로 돌아갈 수 있다. 정원 완료는 기존처럼 물레방아 복원 이후에만 처리한다.

수동 R 복귀, D2 깊은 수조의 기존 별도 위험 판정, 퍼즐/공급/동결 상태는 유지했다. 2~9번 배치/물길/소리/카메라/색상 개선은 이 변경에 포함하지 않았다.

## 변경 파일

- `Assets/EverflowMap/Runtime/EFV2FallRecovery.cs`: 명시적 외곽 영역/최하단 판정.
- `Assets/EverflowMap/Runtime/EFV2PuzzleWorld.cs`: 새 판정 연결, 조기 정원 체크포인트 방지, 재시작 시 진단 초기화.
- `Assets/Scenes/Everflow_Map_v2_test_with_puzzle.unity`: 외곽 영역 설정 저장.
- `Assets/EverflowMap/Editor/EFV2FallRecoveryChecks.cs`: 실제 중력/충돌 낙하 회귀 검사.
- `Assets/EverflowMap/Editor/EFV2PuzzlePlayChecks.cs`: 기존 C 내부 낙하 복귀 가정을 실제 S 외곽 걸어 나가기 검사로 변경.

## 검증 자료

최종 실제 물리 검사 **24/24**, 기존 발판/외곽 이동 입력 검사 **29/29** 통과. 전체 게임 연속 완주 검사는 이번 항목에서 다시 실행하지 않았다.

- `checks.txt`: 실제 중력으로 D1 발코니, 지하 통로, 정원 바닥 착지, 외곽 4방향/최하단 복귀, 능력 모드 정지·재개, 조기 정원 R 복귀 검사. 시작 위치와 기억된 체크포인트는 재현을 위해 명시적으로 배치했으며, 낙하/착지/복귀 처리를 우회하지 않았다.
- `physical-falls.mp4`: 물리 재현 검사 녹화. 기존 근접 카메라 문제는 아직 수정 전이므로 일부 화면이 캐릭터에 가려진다(6번 항목).
- `platforms-and-exterior-input.txt`: 기존 발판·능력 사용 및 실제 W 이동으로 외곽을 걸어 나가 C 안전 지점으로 복귀하는 검사. 29개 통과. 초기 발판/체크포인트 배치가 있는 분리 검사이며 전체 게임 연속 완주 결과는 아니다.
- `first-run-fixture-adjustment.txt`: 첫 재현에서 상부 지형 위에 내려앉은 위치를 잘못 D1 바닥과 비교한 실패 기록. D1 바닥 위의 시작점으로 바로잡은 후 다시 검사했다. 이 때문에 지형이나 낙하 로직을 우회하지 않았다.
- `before/`: 변경 직전 씬/코드 백업.

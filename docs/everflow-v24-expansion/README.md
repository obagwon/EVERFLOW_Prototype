# EVERFLOW v2.4 기존 맵 확장 설계

[기획서 v2.4](../EVERFLOW_redesign_v2.4.md) · [전체 평면도](plan.png) · [높이·수로 단면도](sections.png) · [배치 좌표 원본](layout.json)

팀원이 기존 `EF_Map_v2.fbx`를 확장할 때 적용할 1차 제작 치수다. Unity 좌표 단위는 m이며 이 문서의 좌표는 (X, Y, Z) 순서다. 바닥은 보행면 높이를 뜻한다. 기존 위치는 FBX 메시와 씬 원점에서 확인했다. 새 좌표와 치수는 이번 설계에서 정한 모델링 기준값이며, 플레이 검증은 그레이박스에서 진행한다.

W 접근은 기존 협곡의 동쪽 면을 이용한다. 바퀴가 있는 협곡 바닥으로 곧장 떨어지는 대신 설계 좌표의 지그재그 정비길을 따라 (−82.5, −12, −10)에 도착한다. 8과 W 사이에는 급한 단차를 정원 입구의 뿌리 통로로 처리한다. 절벽 아래 있는 폭포 연출과 안전 착지 선반을 다른 높이에 둔다.

## 5. 두 물길과 최종 씬

**B 수조 지류**의 바닥은 Y=2.0, 누수구 바닥 2.8, 초기 수위 3.0, 정원 수로 입구 3.6, 봉합 후 목표 수위 3.7, 벽 상단 4.2다. 얼음 봉합부는 Y=3.9까지 올라오고 수위 상승 4초를 적용한다. 정원 수로로 물이 넘어간 뒤 잎이 펼쳐지고 정원에 도착해야 회수된다. 해동 시 수위가 낮아지며 회수 완료 후에는 복귀문이 열린 상태를 유지한다.

**본류**는 H 저수지 Y=20.55 → G 공급 Y=15.23 → 최종 수문 개방 뒤 계곡 출구 Y=14.4 → 서쪽 벽 수로 Y=13.0, 10.0, 6.0 → 기존 협곡 Y≈−11.9 → W 공급 턱 Y≈−12.3 → 하부 수면 Y≈−17.82 순으로 내려간다. 큰 낙차는 물길 단면에서 수직 낙수와 받이로 표현한다. 수로 순폭 2m, 지지대 포함 3.5m를 잡고, 서쪽 보행로를 지나는 곳에서는 위쪽 수로 데크나 절벽 쪽 우회로를 쓴다. 상단 Y=6~13의 노출 수로와 낙수 받이는 이번에 추가할 모델이다. W에서 G로 올라가는 케이블은 물길과 별도의 경로를 쓴다. 중간 지지대를 두고 교차 보행면 위로 4m 이상 확보한다.

**풍차탑 내부 씬**은 로컬 좌표 기준 약 30×24m, 천장 순높이 8m로 잡는다. 입구 발코니 Y=0, 근접·원거리 착지 턱 Z=−5/+5, 발판 정지 중심 Z=−3.3/+3.3이다. 발판은 3×3m, 속도 1.4m/s부터 적용한다. 조작대는 (0, 0, 7), 수로 회전축 (5, 1.3, 6), 물받이 (8, 1.1, 8), 주 수문 (5, 2.8, 4), 출구 (10, 0.3, 9)다. 수로 입구에서 출구 쪽으로 0.2m 이상 낙차를 주고, 흔들리는 수로가 물받이에 맞은 상태에서 FREEZE로 고정되면 BLOOM으로 열린 수문의 물이 출구에 도달한다. 외부 본류, 물레방아, 풍차는 완료 상태를 받아 이어서 연출한다.

이름별 위치·접합점·동선 꺾임점은 [layout.json](layout.json)에 있다. 정적 지형, 움직이는 부품, 물 외형을 분리해 넘기면 장치별 좌표와 회전 범위를 맞추기 쉽다. 모델링 의뢰 시에는 평면도와 단면도를 같이 보고, 서로 다른 물길의 높이와 퍼즐 통과 폭을 먼저 확인한다.

기존 좌표 근거는 [FBX 인벤토리](../v2-exploration/fbx-inventory.json)와 [기존 씬·스크립트 가이드](../EVERFLOW_V2_Scene_And_Script_Guide.md)다. 카메라 시야, 기존 지형과 만나는 지점의 충돌, 수로 출구 위치는 모델이 배치된 뒤 확인할 항목이다.
